STEP 3: ADD PROPER VALIDATION (Day 5)
--------------------------------------

Current validation issues:
- Only basic HTML5 required validation
- No frontend validation messages
- Backend validation errors not shown per field

Solution: Add validation component

Create: <x-validation-error /> component
<div x-show="errors.{{ $name }}" class="validation-error">
    <span x-text="errors.{{ $name }}"></span>
</div>

Alpine.js validation object:

    file_no: '',
    mbl_no: '',
    office_id: '',
    eta: '',
    // ... all fields
}

Display errors inline under each field:
<x-gf-input name="mbl_no" label="MB/L No." required x-model="form.mbl_no" />
<x-validation-error name="mbl_no" />

Backend validation rules (already exist):
✓ UpdateOceanImportRequest.php
✓ StoreOceanImportRequest.php

We just need to wire frontend errors from backend response.

Component File: resources/views/components/gf-select.blade.php
---------------------------------------------------------------

@props([
    'name',
    'label',
    'options' => [],
    'optionValue' => 'id',
    'optionLabel' => 'name',
    'required' => false,
    'model' => '',
    'placeholder' => 'Select...',
])

<div class="form-group-gf">
    <label class="form-label-gf">
        @if($required)
            <span style="color:red;">* </span>
        @endif
        {{ $label }}
    </label>
    <div class="form-input-container">
        <select 
            name="{{ $name }}" 
            class="form-control-gf" 
            {{ $attributes }}
            @if($required) required @endif
        >
            <option value="">{{ $placeholder }}</option>
            @foreach($options as $option)
                <option value="{{ $option->$optionValue }}">
                    {{ $option->$optionLabel }}
                </option>
            @endforeach
        </select>
    </div>
    <x-validation-error :name="$name" />
</div>


Component File: resources/views/components/gf-input.blade.php
--------------------------------------------------------------

@props([
    'name',
    'label',
    'type' => 'text',
    'required' => false,
    'readonly' => false,
    'placeholder' => '',
])

<div class="form-group-gf">
    <label class="form-label-gf">
        @if($required)
            <span style="color:red;">* </span>
        @endif
        {{ $label }}
    </label>
    <div class="form-input-container">
        <input 
            type="{{ $type }}" 
            name="{{ $name }}" 
            class="form-control-gf"
            @if($readonly) readonly style="background:#f5f5f5;" @endif
            @if($required) required @endif
            @if($placeholder) placeholder="{{ $placeholder }}" @endif
            {{ $attributes }}
        />
    </div>
    <x-validation-error :name="$name" />
</div>


Component File: resources/views/components/validation-error.blade.php

@props(['name'])

    x-show="errors.{{ $name }}"

>
    <i class="fa fa-exclamation-circle"></i>
    <span x-text="errors.{{ $name }}"></span>
</div>
