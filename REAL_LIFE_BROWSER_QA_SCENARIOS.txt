TECHNICAL FINDINGS & ROOT CAUSE ANALYSIS
====================================================================================================

Finding 1 — SAVEPOINT Trans Counter After pcntl_fork():
 Root Cause: pcntl_fork() inherits the parent process's Laravel DB connection instance including
             its `$transactions` counter. If the parent had any open/closed transaction during setup,
             the counter was non-zero, causing "SAVEPOINT trans2 does not exist" errors in children
             when DocumentSequenceService::generateSequence() calls DB::transaction() (level 2).

Finding 2 — OceanExport Has No 'status' Column:

Finding 3 — CN Guard DB::rollBack() in Nested Transaction:
 Root Cause: InvoiceController::store() called DB::rollBack() inside the CN amount guard before
             returning a 422 response. DocumentSequenceService::generateSequence() uses DB::transaction()
             creating a savepoint; calling rollBack() at nesting level 1 tried to release a non-existent
             savepoint when called from within a concurrent nested transaction context.
 Fix Applied: Removed the DB::rollBack() call from the CN guard. The outer try/catch with DB::rollBack()
              correctly handles genuine exceptions. Early returns (422/redirect) don't need explicit rollback.
